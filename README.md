# LLM Engineering Lab

A collection of small projects and experiments created to learn LLM application development, agents, and orchestration frameworks.

## Technologies

- Google ADK
- LangChain
- LangGraph
- FAISS
- MCP / Toolbox

## Projects

- **adk-learning** — Initial experiments with Google ADK.
- **adk-coder-agent** — Coding assistant with a specialized web search agent.
- **adk-trello-agent** — Task management agent integrated with Trello.
- **adk-db-mcp** — Agent for interacting with PostgreSQL data through Toolbox.
- **langchain-langgraph-learning** — Experiments with agents, RAG, structured outputs, and LangGraph orchestration.
- **langchain-summarize-agent** — Experiment with document summarization using LangChain.
